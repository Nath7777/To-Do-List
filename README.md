# To-Do List – Développement d'applications

Application de gestion de tâches simple développée dans le cadre de mes études en développement d'applications. Ce projet me permet de mettre en pratique mes compétences en programmation et en gestion des interactions utilisateur.

**Fonctionnalités :**
- Ajouter de nouvelles tâches.
- Cocher les tâches terminées.
- Supprimer les tâches de la liste.
- Interface simple et intuitive pour gérer ses tâches quotidiennes.

**Objectif :** apprendre à manipuler des données, gérer les actions de l'utilisateur et développer une application interactive.
